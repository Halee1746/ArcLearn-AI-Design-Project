# ArcLearn AI - UI/UX Design Project

## Overview

ArcLearn AI is an AI-powered learning platform designed to help students learn more effectively through personalized learning paths, AI tutoring, practice tests, progress tracking, and career recommendations.

## Features

* AI Tutor Chat
* Personalized Learning Paths
* Course Library
* Practice Tests
* Progress Analytics
* Career Recommendations
* Responsive Mobile Design

## Project Deliverables

* Competitor Analysis
* User Personas
* User Flows
* Wireframes
* Design System
* High-Fidelity Designs
* Interactive Prototype
* Mobile Designs
* Case Study
